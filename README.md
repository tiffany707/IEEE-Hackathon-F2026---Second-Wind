# Setup & Development

Follow these steps to set up and run the server locally.

## Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

## Getting Started

1. **Navigate to the project directory:**
   ```bash
   cd "01-energy-and-infrastructure-systems/Case 3 - Autonomous Alberta Wind-and-Demand Balancing Agent"
   ```

   ```bash
   npm install
   npm run dev
   ```
